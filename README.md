# Montreal Explorer

Welcome to Montreal Explorer, your ultimate guide to discovering the vibrant heart of Canada's cultural capital. This application is a web-based guide to the city of Montreal, showcasing its districts, cuisine, culture, and local stories.

![Montreal Explorer Screenshot](https://picsum.photos/seed/montreal-explorer-readme/1200/600)

## ✨ Features

- **Interactive Guides:** Explore different districts, from the historic streets of Old Montréal to the trendy Plateau.
- **Culinary Journey:** Discover Montréal's iconic food scene, including poutine, bagels, and smoked meat.
- **Cultural Insights:** Learn about the city's rich history, arts, and bilingual heritage.
- **Blog:** Read articles and stories from locals and explorers.
- **Responsive Design:** Fully responsive and accessible on all devices.

## 🚀 Tech Stack

This project is built with a modern, component-based architecture:

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Components:** [ShadCN UI](https://ui.shadcn.com/)
- **AI/Generative:** [Genkit](https://firebase.google.com/docs/genkit)
- **Icons:** [Lucide React](https://lucide.dev/)

## 🏁 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- Node.js (v18 or later)
- npm or yarn

### Installation & Setup

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/your-username/montreal-explorer.git
    cd montreal-explorer
    ```

2.  **Install dependencies:**
    ```sh
    npm install
    ```

3.  **Run the development server:**
    ```sh
    npm run dev
    ```

Open [http://localhost:9002](http://localhost:9002) with your browser to see the result.
