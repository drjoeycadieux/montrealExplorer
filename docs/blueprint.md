# **App Name**: Montreal Explorer

## Core Features:

- Landing Page: Visually appealing landing page that will display main blog sections about Montreal.
- Blog Post Cards: Cards for each blog post featuring an image, title, short description, and a link to the full post.
- Header Navigation: Fixed header with logo, search bar, and main navigation links (e.g., categories, about, contact).

## Style Guidelines:

- Primary color: Deep burgundy (#800020), inspired by Montreal's rich history and European influence.
- Background color: Off-white (#F8F8FF), a desaturated version of the primary for a sophisticated feel.
- Accent color: Gold (#FFD700) for highlights and calls to action, creating a luxurious touch and good contrast.
- Headline font: 'Playfair', a modern serif with an elegant feel.
- Body font: 'PT Sans', a humanist sans-serif, to ensure readability and contrast to the headings.
- Use simple, line-based icons to represent different categories or features. Use icons related to travel and Montreal.
- Cards should have a uniform size, good padding, and clear separation to create an easy-to-scan grid layout.
- Subtle transitions and hover effects on cards to enhance the user experience.
